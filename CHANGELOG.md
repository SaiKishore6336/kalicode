# Changelog

All notable changes to KaliCode are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-21

### Added

- Monaco-based editor with 90+ languages, diagnostics, formatting, multi-cursor,
  minimap, sticky scroll, and find/replace.
- Workspace explorer with lazy loading, file operations, drag-and-drop, and
  Quick Open indexing.
- Project-wide search and replace with case, whole-word, and regex modes.
- Git panel with branch switching, staging, commits, and side-by-side diffs.
- Real PTY terminal (Python bridge) with multiple sessions and themed xterm.js.
- Run panel with language commands and detection for npm, Make, pytest, Django,
  and Docker Compose tasks.
- Four themes: Kali, Midnight, Graphite, and Daylight.
- Session restore for the last folder, open files, and active tab.
- Per-user, system-wide, and prefix installers with application-menu entries.
- Self-contained `.deb` packaging that bundles the Electron runtime.
